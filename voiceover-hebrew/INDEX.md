# Hebrew voiceover texts (slow reading)

One file per recording. Each file has the Hebrew with full vowels, as on the site, plus ElevenLabs tags:

- `[slowly]` at the start, to ask for a slow reading.
- `[pause]` at the end of each line, for a short breath before the next.

Paste the whole file into ElevenLabs. Use the Speed setting as well if the result is still fast (around 0.8 is a good start).

Name each finished recording as in the 'Audio file name' column.

## Divine Name

The site writes the Name as יְהֹוָה (with prefixes: לַיהֹוָה, בַּיהֹוָה, וַיהֹוָה). A voice engine would sound it out letter by letter, so these files spell it as it is said: אֲדֹנָי (לַאדֹנָי, בַּאדֹנָי, וַאדֹנָי). Where it is written יֱהֹוִה it is read Elohim, so it is spelled אֱלֹהִים.
